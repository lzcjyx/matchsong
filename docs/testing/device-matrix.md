# 真机与模拟器设备矩阵（Device Matrix）

- **版本：** 0.1.0
- **日期：** 2026-07-31
- **里程碑：** M0.4（执行于 PLAN M10.3 设备矩阵测试；人工录音测试 M3.7 前置）
- **配套：** TESTING.md §9 真机测试要求、docs/testing/manual-test-checklist.md

## 1. 覆盖目标（PLAN M10.3 + SPEC §11 兼容）

- 至少覆盖：**低端 / 中端 / Pixel 或接近原生 / Samsung / 中国厂商（Xiaomi、OPPO、vivo）各 ≥ 1 台**；
- **不同 Android 版本**：minSdk 26（Android 8.0）至 targetSdk 36（Android 16）跨度；
- **三种采集方式**：有线耳机（3.5mm / USB-C）、蓝牙耳机（A2DP）、手机内置麦克风；
- 附加场景：外放伴奏（M3.7 人工清单）。

## 6. 更新规则

- 每次获取新设备：更新 §3 可用状态与获取方式；M10.3 前集齐全部行；
- 每台真机完成一轮测试后：在 manual-test-checklist.md 记录 设备/Android 版本/日期/结果；
- 设备系统升级（如 Android 大版本 OTA）后：重跑该行设备的关键用例并更新版本列。
