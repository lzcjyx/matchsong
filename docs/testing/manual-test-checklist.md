# 人工测试检查清单（Manual Test Checklist）

- **版本：** 0.1.0
- **日期：** 2026-07-31
- **里程碑：** M0.4（M3.7 人工测试、M10.4 稳定性、M11.3 Internal Testing 依据）
- **配套：** TESTING.md §9、docs/testing/device-matrix.md、docs/bugs/bug-log.md

## 0. 执行说明

- 每条记录：**设备 / Android 版本 / 日期 / 执行人 / 结果**；失败项必须提 Bug（`docs/bugs/bug-log.md`），P0/P1 阻止发布（SPEC §11、PLAN M10.6）。
- 设备组合按 device-matrix.md；录音场景（C 组）在每台矩阵设备上至少执行一轮，音频附件（内置/有线/蓝牙/外放伴奏）轮换覆盖（M3.7）。
- 每项以最终用户视角操作 Debug 构建；关键数据删除类操作（G/H 组）执行前确认不破坏测试数据。
- 结果框：`□ 通过　□ 失败`
