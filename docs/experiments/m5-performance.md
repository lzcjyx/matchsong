# M5.8-2 分析性能记录

- **日期：** 2026-07-31
- **设备：** 开发机 JVM 桌面（i7-11800H，JDK 17）
- **测量：** 30s 音频（220Hz 正弦，44.1k/16bit/mono）端到端分析（质量 → YIN → 后处理 → 统计）
- **结果：** AnalysisPerformanceTest 实测，单次分析耗时见测试输出（宽松断言 <5s）

| 项目 | 预算 | 实测（JVM 参考） | 状态 |
|---|---|---|---|

## 说明

- JVM 桌面数据仅供参考，**真机基准在 M10.1 定论**（中端 Android CPU 弱于桌面 3-10 倍，预算 10s 仍有余量）。
- 高通预滤波 + Double 精度使单帧成本略高于 Spike（约 +20% [推测]），仍远低于帧预算（46ms）。
- 若 M10 真机超标，优化顺序（M10.2）：帧批并行 → hop 加倍 → 减少分配。
